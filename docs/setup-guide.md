# Setup Guide — NIVARA

## Environment Configuration

### Frontend
1. Navigate to `client/`
2. Duplicate `.env.example` as `.env`:
   ```bash
   cp .env.example .env
   ```
3. Update `VITE_API_BASE_URL` as needed.

### Backend
1. Navigate to `server/`
2. Duplicate `.env.example` as `.env`:
   ```bash
   cp .env.example .env
   ```
3. Update `MONGO_URI` with your MongoDB Atlas connection string.
